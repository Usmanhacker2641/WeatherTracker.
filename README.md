# NatureMotion - Natural Live Wallpapers

A beautiful website for downloading high-quality natural live wallpapers.

## Features

- Browse stunning natural live wallpapers by category
- Preview wallpapers before downloading
- Responsive design for all devices
- High-quality video wallpapers
- Easy download functionality

## Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome for icons
- Responsive design principles

## Getting Started

1. Clone the repository
2. Open `index.html` in your browser
3. Browse and enjoy the wallpapers!

## Categories

- Forests
- Oceans
- Mountains
- Waterfalls
- Aurora
- Sunsets
